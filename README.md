# نبض 2.0: وكيل ذكاء اصطناعي بشخصية إيموجي ثلاثية الأبعاد

## ما الجديد
- **إيموجي ثلاثي الأبعاد تفاعلي**: يتابعك بعينيه، يرمش، يتحرك فمه مع الكلام، ويتفاعل حين تلمسه. اسحبه ليدور. له 8 تعابير يختارها حسب الموقف. لون هوائيه وحلقته يتغير مع حالته: يستمع (أخضر)، يفكر (بنفسجي)، يعمل (برتقالي). ويمكنك تغيير لونه من الإعدادات.
- **وكيل متكامل**: يضع خطة، ينفّذها خطوة خطوة بأدوات حقيقية (حتى 30 خطوة للمهمة الواحدة)، ثم يسلّمك النتيجة. يمكنك إيقافه في أي لحظة بزر ■.
- **يطوّر نفسه**:
  - `create_tool`: يكتب كود أداة جديدة، يختبره، ثم يثبّته بشكل دائم.
  - `learn_skill`: يحفظ طرق العمل الناجحة وتصحيحاتك ليتبعها لاحقاً.
  - التثبيت يحتاج موافقتك، وترى الكود قبل الموافقة. تجد كل ما طوّره في الإعدادات ويمكنك حذفه.

## أدواته
| الأداة | العمل |
|---|---|
| web_search / fetch_page | البحث في الإنترنت وقراءة الصفحات (بدون مفتاح) |
| run_js | تنفيذ كود في بيئة معزولة: حسابات، تحليل بيانات، استدعاء أي واجهة ويب عامة |
| weather | الطقس (Open-Meteo، بدون مفتاح) |
| write_file / read_file / list_files | مساحة عمل للتقارير والملفات، تفتحها وتشاركها من الإعدادات |
| update_plan | خطة المهمة تظهر لك في المحادثة |
| remember / forget | ذاكرة دائمة عنك |
| set_reminder / list_reminders | إشعارات تصلك حتى والتطبيق مغلق |
| home_control | التحكم بالأجهزة عبر Home Assistant |
| create_tool / learn_skill | تطوير الذات |

## مصدر الذكاء (من ⚙️)
- **Claude**: أقوى خيار للمهام المعقدة. يحتاج مفتاح Anthropic.
- **متوافق مع OpenAI**: أي خادم بنفس الصيغة:
  - **Ollama على حاسوبك، بدون مفتاح**: الرابط `http://<IP-الحاسوب>:11434/v1`، والنموذج مثلاً `qwen2.5:7b` أو `llama3.1`. اختر نموذجاً يدعم استخدام الأدوات (tools).
  - أو OpenRouter أو Groq أو Gemini، بمفاتيحها.

ملاحظة: النماذج المحلية الصغيرة أضعف في المهام الطويلة متعددة الخطوات.

## البناء (GitHub Actions)
1. ارفع محتويات المجلد إلى مستودع GitHub، مع مجلد `.github`.
2. افتح تبويب Actions وانتظر انتهاء **Build APK**.
3. نزّل `nabd-apk` وثبّت `app-debug.apk`.

## الأمان
- الأدوات المطوَّرة تعمل في Web Worker معزول، بلا وصول للذاكرة أو المفاتيح أو الواجهة.
- قواعده الأساسية مكتوبة في الكود، ولا تلغيها مهارة ولا صفحة ويب. يعامل محتوى الإنترنت كبيانات لا كأوامر، ولا يتجاوز أنظمة الحماية، ويسأل قبل أي إجراء حساس.
- كل البيانات محفوظة على هاتفك فقط.

## الملفات
- `www/avatar.js`: الإيموجي ثلاثي الأبعاد (three.js r160 مضمّن في `www/lib`، ويعمل بدون إنترنت)
- `www/agent.js`: محرك الوكيل والأدوات ومزوّدات الذكاء
- `www/sandbox-worker.js`: البيئة المعزولة لتنفيذ الكود
- `www/app.js` و `www/index.html`: الواجهة
